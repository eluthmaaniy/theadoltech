# Adoltech Shopify Studio

Use this improved version:

Create a personal portfolio website for Adebisi Olamide (Adoltech) focused on Shopify-related services.

Structure the website with these pages:

About page (this will serve as the landing page)

Reviews page

Portfolio page

Full portfolio page (detailed case studies or projects)

Contact page

Design direction:

Style it like a Shopify Partner or Shopify agency website

Keep the theme strictly ash, black, and white

Do not use gradients anywhere

Use Inter font across the entire site

Use Remix Icon library for icons

Layout and UX:

Clean and structured layout with clear sections

Strong focus on readability and spacing

Make navigation simple and easy to follow

Highlight services, past work, and testimonials clearly

Portfolio:

Showcase Shopify projects with images, short descriptions, and results

Full portfolio page should include detailed breakdowns of selected projects

Responsiveness:

Fully responsive on mobile, tablet, and desktop

Ensure spacing, typography, and layout adapt properly across screen sizes

Extra notes:

Keep the design unique, not a clone of any existing site

Maintain a modern, minimal feel using only the defined color scheme

Avoid unnecessary elements or clutter
